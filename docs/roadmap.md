## 技術的検討事項

| 項目 | 現状（MVP） | 理想（将来） |
|------|------------|--------------|
| 画像生成 | 手動アップロード | SD/DALL-E API自動生成 |
| キャラ一貫性 | プロンプトのみ | LoRA/IP-Adapter/seed固定 |
| テキスト組版 | 横書きのみ | 縦書き・装飾フォント |
| 出力品質 | 150dpi PNG | 600dpi 入稿対応 |
| データ永続化 | ローカルファイル | DB + クラウドストレージ |
| 実行環境 | ローカルのみ | クラウド/SaaS |
